# Changes from upstream

Anker eufy Integration is based on
[alaraun/homeassistant-eufy-home-security](https://github.com/alaraun/homeassistant-eufy-home-security)
(MIT; its copyright notice is kept in [LICENSE](LICENSE)), taken at upstream commit
`2a76edf` (release 0.4.21). It is a separate integration with its own domain and
versions: upstream changes are brought in only when chosen
([docs/upstream-sync.md](docs/upstream-sync.md)).

Last synced upstream commit: `2a76edf`.

The Python library is our own `anker-eufy-security` (import `anker_eufy_security`,
[source](https://github.com/abz2much/anker-eufy-security)), based on alaraun's
`eufy-home-security` v0.4.19 (MIT) and installed from PyPI at the version in
`manifest.json`. Its own name means it never shares an installed copy with the upstream
integration's library, so the two pins are independent. Its changes from upstream are in
that repository's CHANGES-FROM-UPSTREAM.md.
